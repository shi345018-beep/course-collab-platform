# ADR-004 保持 v1 接口契约不变

- 状态：已采纳
- 日期：2026-11-26
- 决策者：第六组

## 背景

重构期间前端、测试与演示脚本都依赖现有接口；若同时改接口，将无法判断问题来自重构还是契约变化。

## 决定

v2 保持所有 `/api/*` 路径、请求字段与响应结构 `{ code, data }` 不变；错误结构保持 `{ code, message }`。

## 理由

1. 20 项既有测试可直接作为回归护栏；
2. 前端无需同步改造，降低联调风险；
3. 接口不变时，重构的正确性可以用"行为一致"衡量。

## 后果

- 新能力只能新增接口，不能修改既有字段含义；
- 若确需破坏性变更，必须新增版本前缀并单独记录 ADR；
- 前端迁移到 `api-client` 是内部重构，不改变调用契约。
