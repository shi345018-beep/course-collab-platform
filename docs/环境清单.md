## 一、运行环境

| 项目 | 要求 | 本次验证环境 |
|---|---|---|
| 操作系统 | Windows 10 / 11、macOS、Linux 均可 | Windows 11 |
| Node.js | **22 或以上**（使用内置 `node:` 模块） | **v24.19.0** |
| npm | **不需要**（零第三方依赖，无需 `npm install`） | 本机未安装，仍可正常运行 |
| 浏览器 | Chrome / Edge / Firefox 现代版本 | Chrome 最新版 |
| 磁盘 | 约 10 MB | — |
| 内存 | 512 MB 以上 | — |

> 本项目刻意做成**零依赖**：不需要 `npm install`，不需要数据库，不需要编译工具链。
> 只要有 Node.js，解压后即可运行，避免课程机器网络受限或包管理器缺失导致跑不起来。

## 二、启动方式

### 方式一：双击（推荐）

双击项目根目录的 `start.bat`。
首次运行会自动执行 `node seed.js` 生成演示数据，然后启动服务。

### 方式二：命令行

```bash
cd 项目目录
node seed.js      # 仅首次运行，生成演示数据
node server.js    # 启动服务
```

启动成功后控制台输出：

```
高校课程协作与评审平台已启动
本机访问: http://localhost:8099
局域网:   http://192.168.x.x:8099
```

浏览器访问 <http://localhost:8099>。

### 方式三：指定端口

```bash
set PORT=8099 && node server.js
```

## 五、依赖说明

第三方依赖：**无**。

使用的均为 Node.js 内置模块：

- `http` / `https`：HTTP 服务
- `fs` / `path` / `os`：文件与系统信息
- `crypto`：scrypt 密码哈希、随机 token
- `child_process`（仅测试脚本）：启动被测服务

因此 `node_modules` 为空，`package.json` 中 `dependencies` 为空对象。

## 六、数据与重置

- 数据保存在 `data/db.json`，采用「临时文件 + 原子改名」写入，避免断电写坏。
- 重置演示数据：`node seed.js`（会覆盖现有数据）。
- 备份：直接复制 `data/db.json`。
- `data/db.json` 已被 `.gitignore` 排除，不进入版本库。

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 端口 8099 被占用 | 已有实例在运行 | `set PORT=8081 && node server.js`，或关闭旧窗口 |
| 打开后提示"无法连接" | 服务未启动 | 在项目目录执行 `node server.js`，看到"已启动"后再访问 |
| 页面空白 | 浏览器缓存了旧版 | Ctrl+F5 强制刷新 |
| 局域网访问不了 | Windows 防火墙拦截 | 允许 Node.js 通过防火墙的专用网络 |
| 数据被改乱 | 演示操作 | 关闭服务后执行 `node seed.js` 重置 |
