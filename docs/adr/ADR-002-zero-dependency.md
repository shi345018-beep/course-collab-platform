# ADR-002 保持零第三方依赖

- 状态：已采纳
- 日期：2026-11-26
- 决策者：第六组

## 背景

课程机器可能没有 npm、无法访问外网镜像，v1 已通过零依赖实现跑通全部流程。

## 决定

v2 继续只使用 Node 内置模块（http、fs、crypto、path、os）。`package.json` 的 `dependencies` 保持为空。

## 理由

1. 评分环境可复现：解压即可运行，不受网络影响；
2. 减少供应链风险与版本漂移；
3. 当前业务规模不需要框架提供的额外能力。

## 后果

- 路由、校验、日志需要自行实现，但代码量可控；
- 不允许以"方便"为由引入 express、zod、lodash 等依赖；
- 若未来引入依赖，必须新增 ADR 并说明替代方案。
