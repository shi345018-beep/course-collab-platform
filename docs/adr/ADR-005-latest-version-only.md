# ADR-005 互评只针对最新版本

- 状态：已采纳
- 日期：2026-11-26
- 决策者：第六组
- 关联：课堂实践发现的问题、BR-05、BR-17

## 背景

v1 的 `assign-reviews` 会遍历项目内全部提交物，包括同一迭代的历史版本。成绩汇总只统计最新版本，因此旧版本上的评审任务不会被计分，评审人做了无效工作。

## 决定

v2 在分配互评前，先按「小组 + 迭代」取版本号最大的提交，再为这些最新提交分配评审任务。

## 理由

1. 与 BR-17 的语义一致：历史版本仅用于追溯，不作为评分对象；
2. 避免评审任务翻倍与评审人无效劳动；
3. 与成绩汇总口径一致，任务与计分对象一一对应。

## 后果

- 与 v1 行为存在差异，属于有意的缺陷修复；
- 回归测试仍全部通过；
- 若未来需要评审历史版本，必须新增显式配置，而不是默认分配。
